**逐条对照**

- **8 个一级 tab** —— `首页渲染，8 个一级 tab 可见`：断言 `一级场景分类` 导航下恰好 8 个链接，且逐个核对 `sceneCategories` 的 label 都可见。附带一条 `根路径重定向到语聊房 —— 唯一已实现的场景`。
- **切一级 tab 后二级跟着换** —— `切一级 tab 后二级 tab 跟着换`：从社交（6 个场景）点到游戏（1 个），断言二级导航的链接数与内容都换了。另有 `切换场景时两级 tab 与时间线面板不重建`，用 DOM 节点句柄比对证明它们没被卸载重建。
- **计划中场景进占位页** —— `点计划中场景进占位页`：点二级 tab 上带「待建」标记的场景，断言 `scene-placeholder` 出现且语聊房场景不在页面上。
- **两台手机可见** —— `点语聊房后两台手机可见`：`vr-host` 与 `vr-audience` 都可见。
- **时间线可折叠可展开** —— `可折叠、可展开`：点 `timeline-toggle` 后断言 `.lab-body` 的 `data-timeline` 在 `collapsed`/`expanded` 之间来回切换，且折叠态仍显示条目计数（数据没被清）。
- **env 未配置渲染引导页** —— `渲染引导页，不进场景`：这条**不注入** `__ENV__`（仓库里没有 `.env`，未配置就是默认态），断言 `env-guide` 出现、`scene-voice-room` 不出现。
- **控制台无未预期报错** —— 每个用例都挂 `pageerror` / `console.error` / HTTP ≥ 400 三路收集，末尾断言**滤掉预期噪声后为空**。见下。
- **无头 + 浏览器路径** —— `playwright.config.ts` 原本就是 `headless: true`，且 `launchOptions` 在约定路径存在时用 Chrome for Testing、不存在时回退自带浏览器。本票沿用，未改。
- **新旧都绿** —— `npm run test:e2e` 现在依次跑根目录与 `demos/voice-room` 两套：根目录 **75 passed / 3 skipped**（新 25 + 遗留 50），SPA **10 passed / 2 skipped**。

**「控制台无未预期报错」怎么做才不是空断言**

占位 App ID 必然让 RTM 登录失败（SDK 打 `Error Code -10023: login failed`），这是**有意的**：e2e 不验证 Agora 后端可用性，塞真实凭证会让测试在没网、凭证过期、配额用尽时无故变红。所以断言的是「没有**未预期**的报错」——白名单只列鉴权/连接失败与无音频设备这两类的特征串。

白名单里**刻意不放** `error`、`failed` 这种通用词，也没用 `RTM:ERROR` 这个宽泛前缀——那会把真实的渲染错误一起吞掉，断言就形同虚设。实际踩到过：第一版白名单写了 `AgoraRTMError`，但 SDK 打的是 `Error Code -10023`，5 个用例因此变红。修法是加那个**具体错误码**而不是放宽前缀。

**修掉的两个 pre-existing 故障**

两处都不是本票新引入的，但都挡着最后一条勾选项，所以在本票修掉。

**遗留 E2E 在票 12 之后就一直是红的。** 票 12 把 `index.html` 指向新骨架入口，于是开发服务器的 SPA fallback 把 `/scenarios/*` 全交给新骨架，遗留用例找不到 `h1` 就超时。`git diff HEAD --stat` 确认 `e2e/`、`index.html`、`playwright.config.ts` 三处本票之前都没人碰过；票 12 的 Comments 也写明它当时用「单入口构建」代替了浏览器验证，没跑 e2e——这个洞就是那时留下的。修法是在 `vite.config.ts` 加一个开发服务器中间件，把 `/scenarios/*` 的文档请求重写到 `/legacy.html`，**两份 spec 都不用改**：URL 空间的归属是服务器的职责，不该让测试拿它当参数。

**开发服务器下 vendor SDK 起不来。** `does not provide an export named 'default'`——vendor 里的 RTM SDK 是 UMD/CJS 产物，生产构建走 Rollup 的 commonjs 转换没事，dev 不预构建它时按 ESM 解析就炸，整个 app 白屏。修法是 `optimizeDeps.include: ['agora-rtm']`，与 `demos/voice-room` 那份配置一致（它早就这么写了）。软链进来的本地包，Vite 的自动依赖发现不可靠，所以必须显式列。

**脚本变化**：`test:e2e` 原先只委托给 `demos/voice-room`，根目录那套 e2e **没有任何脚本会跑到**。现在改成先跑根目录再跑 SPA。

**验证**：`npm run test:e2e` 根目录 75 passed / 3 skipped、SPA 10 passed / 2 skipped；`npm test` 404 + 64 passed；`npm run build`（含 `tsc -b`）绿。
