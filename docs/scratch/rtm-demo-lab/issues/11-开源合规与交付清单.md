## Question

对外开源需要满足哪些条件？清单是什么？

需要定：

- 许可证选择。
- README 的形态：面向客户的"这是什么、怎么跑、怎么拷走 rtm.ts 集成"三段式，与现有中文 README 的关系。
- 仓库里必须清理的东西：本机绝对路径、任何凭证或 appId 残留、`.env` 是否入库、`docs/inputs/` 这类内部输入是否随开源发布。
- 遗留根目录 `src/`（24 场景实验室）在开源版本里的处置：删除、还是保留但明确标注废弃。
- 贡献指南与 issue 模板是否需要。
- 版本历史：当前仓库没有任何 commit，开源前需要建立基线（本票只记录需求，不代替用户执行 git 操作）。

被 `03` 阻塞：依赖可安装性是"外部机器能跑通"的前提，也是 README 里安装步骤的写法依据。

## Answer

### 一、SDK 包：link 到本地 2.3.0，待发布后切 npm（用户决策）

包路径更新为 `/Users/zhouxueqin/Desktop/agora-rtm-demo/agora-rtm@2.3.0`。**已核验**：版本是 `2.3.0` 正式版（不再是 `2.3.0-beta.0`），4 个文件、零 runtime 依赖、peer 依赖 `agora-rtc-sdk-ng@^4.24.3`、license 字段 `Apache`。

**但它仍未发布到 npm** —— `npm view agora-rtm versions` 最高仍是 `2.2.4`。所以过渡期照 `03` 的方案走，只是版本号改为 `2.3.0`：

1. 把该目录 4 个文件复制进仓库 `vendor/agora-rtm-2.3.0/`。
2. `package.json` 写 `"agora-rtm": "file:./vendor/agora-rtm-2.3.0"`（相对路径，不是绝对路径）。
3. 用户确认发布后，改为 `"agora-rtm": "^2.3.0"` 并删除 `vendor/`。

用 vendor 复制而非 `npm link` 到桌面路径：`link` 只在你本机有效，其他人 clone 后仍装不上，达不到「任意机器可跑」的验收标准。

**合规**：用户已指示先用本地包、后续发布，视为已授权在仓库内携带。原先「对外分发未发布 beta 包是否合规」的疑问按此关闭。

### 二、README 必须声明的三件事

1. **多 RTM 实例是实测可行、官方文档未保证。** 官方 migration guide 写明事件回调绑定到 client 实例，跨实例行为无任何说明。本项目一角色一个 client 实例是核心做法，必须写明这一状态，否则客户照抄进生产、日后 SDK 行为变化时会误判归因。来源：<https://docs.agora.io/en/realtime-media/rtm/reference/migration-guide/web>
2. **治理动作不构成信任边界。** 踢人、封禁、强制麦控都是客户端协作行为，生产环境必须在服务端校验。沿用现有 `CLAUDE.md` 的表述，不得改写成「已强制执行的权限控制」。
3. **默认 appId 无 token 鉴权，仅供体验。** 客户接入生产必须换成支持 token 的 appId，并在 `login` 时传入 token —— 代码里保留该参数位。

### 三、两站部署的域名白名单（待核实）

国内站 `doc.shengwang.cn` 与国际站 `docs.agora.io` 是不同域，各自同源部署两份，appId 与接入网关区域不同，防火墙域名白名单也不同。**具体域名清单尚未核实** —— 这是从「两站分立」推出的必然结果，不是查证过的事实。写进 README 前需核对官方域名列表。

### 四、交付清单

- `LICENSE`：MIT（demo 代码本身），并在 README 说明 `vendor/` 下的 SDK 包版权归声网、遵循其自带 license。
- `README.md`：快速开始、`window.__ENV__` 注入契约（两站各一份示例）、目录导览、「哪些文件可以直接拷走」、上述三条声明。
- `.env.example`：本地开发兜底示例。
- 移除仓库内所有硬编码的本机绝对路径（现有 `package.json`、`package-lock.json`、`README.md`、`CLAUDE.md` 均含 `/Users/zhouxueqin/...`）。
- 移除或归档遗留根 `src/` 与 `demos/voice-room/`（`10` 定为本阶段不删，开源前需定论）。
- 确认无凭证入库：不含 App Certificate、不含 token 生成器、不预置任何密钥。
