# 13 — 依赖可安装化

**Blocked by:** None — can start immediately

**Status:** resolved

**What to build:** 任意一台机器 clone 仓库后直接安装依赖就能成功，不依赖某台特定机器上的本地文件路径，且安装结果不随时间漂移。

当前 RTM SDK 依赖指向某台机器上的绝对路径，换机器安装直接失败。这是开源的硬阻塞，且后面所有票都要装依赖，所以优先做。

- [x] 未发布的 RTM SDK 包复制进仓库根的 vendor 目录，复制后核对包内版本号确实是预期的正式版本
- [x] 依赖改为 vendor 的**相对路径**引用
- [x] RTC SDK 从浮动版本锁到确定版本，其余写浮动版本的依赖一并锁定
- [x] 删除锁文件后重装，确认锁文件内不含任何机器专属绝对路径
- [x] 硬断言 SDK 版本的现有测试改为断言新版本号
- [x] 遗留测试全绿
